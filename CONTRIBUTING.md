# Contributing

This is a simple, internal package — it only standardizes the `tsconfig` used across AeroOps monorepo projects.

**External contributions are not accepted.** Issues and Pull Requests from outside the organization will be closed without review.

## Branch flow

No `develop`/`staging`. A single long-lived branch: **`main`**.

Changes go straight to `main` via PR (or a direct commit, at the maintainer's discretion).

## Commit convention

We use [Conventional Commits](https://www.conventionalcommits.org/), validated via commitlint on `commit-msg`.

```
<type>(<optional scope>): <subject>
```

**Allowed types:** `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`.

Examples:

```
chore: bump typescript to 7.0.2
fix(base): correct moduleResolution setting
docs: update README with usage example
```

Every change to this repository must be recorded in a commit. All commit messages must be written in English, including the subject, body, and optional scope.

Do not add co-authorship trailers (e.g. `Co-Authored-By:`) to commit messages, including those generated by AI tools.

## Quality gate

Before committing:

```bash
bun run check-types
```

If it fails locally, it will fail in CI.
